# AI usage documentation

Designed by Thalia.

AI was used to accelerate MVP scaffolding, product framing, deployment documentation, and demo narrative. The human design intent was to build a WhatsApp-native field operations inbox that converts informal agent messages into translated, triaged, searchable operational tickets.

AI-assisted areas:

- Initial TypeScript/React/Express/Prisma scaffold
- WhatsApp webhook handler pattern
- Translation-provider abstraction
- Dashboard copy and product narrative
- Deployment guide and demo flow
- One-page demo deck

Human review areas:

- Product scope: audio ingestion was explicitly excluded from MVP
- Operational assumptions for Haiti field agents
- Privacy and platform-risk framing
- Final deployment commands and environment-variable requirements

No customer data, production credentials, or real private WhatsApp messages were used.
