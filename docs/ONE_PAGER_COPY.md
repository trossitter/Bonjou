## Body

Every field agent in Haiti is already on WhatsApp. Every operations team in the US already has a dashboard. The only thing missing is a translator standing quietly in the middle — one who never sleeps, never misses a message, and doesn't need to be on the org chart.

That's Bonjou.

A Kreyòl message comes in: *POS la pa mache. Kliyan yo pa ka depoze lajan.* The operations dashboard reads: *The POS is not working. Customers cannot deposit money.* Severity: Critical. Branch: PAP-003. The team replies in English. The agent gets a response in Kreyòl. Neither side noticed there was a gap.

Haiti has 10.1 million mobile connections and 39% internet penetration. WhatsApp isn't a workaround — it's the infrastructure. Any tool that asks field agents to download something, log in somewhere, or change how they communicate has already lost.

The demo runs live: Haiti's World Cup qualifier season means transaction volume spikes, agents under pressure, and a US ops team that needs to triage fast. Bonjou handles Haitian Creole, French, and Spanish. It triages by severity automatically. It keeps the original message and the translation side by side so nothing gets lost in the handoff.

No new app. No new training. No per-seat licensing for something agents will never open.
