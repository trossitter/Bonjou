# One-pager copy

Title: Bonjou: WhatsApp-native field ops inbox for Haiti

Subtitle: Converts field-agent WhatsApp reports into translated, triaged, searchable operational tickets.

Why now:
- 1,000+ frontline agents already communicate through informal WhatsApp channels.
- Haiti is mobile-first: 10.1M cellular mobile connections at end of 2025.
- Only 39.3% internet penetration, so workflows must respect low-friction mobile behavior.
- Football is a clean demo hook: Haiti appeared in the 1974 FIFA World Cup, the 2023 FIFA Women's World Cup, and qualified for the 2026 cycle.

Demo promise:
Kreyòl WhatsApp message → English dashboard ticket → severity triage → English reply → Kreyòl response.

MVP excludes audio ingestion.
